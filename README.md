# -FH2-Stance-and-Airride-mod
This mod adds fully adjustable stance and airride features to Forza Horizon 2, allowing you to customize your car's appearance with additional tuning options.  Designed for the FH2 Mod Platform to provide improved compatibility with Azimuth and other supported mods.

**Features**

-Adjustable front and rear camber. (optical no physic impact). Use original sliders for car physic/setups

-Adjustable front and rear wheel spacers.

-Adjustable Airride suspension
Press Left Stick on Controller or "-" on Keyboard for 1,5 seconds for activation

-Extended ride height adjustment via original ride height slider (up to -3 cm / +5 cm).

-Individual optical stance adjustments for the front and rear axles.

-Additional stance sliders integrated into the original suspension tuning menu.

-Vehicle-specific stance profiles.


**Enhancements**

Airride lowering remains active when entering Photo Mode. Airride works on Car-Meets too.
Airride settings are preserved when opening and closing the tuning menu.
Automatic Airride reset when switching vehicles.
Extended suspension height limits using the original in-game sliders.
Optical stance adjustments without changing the original driving physics.
English menu labels for all additional stance controls.
Automatic detection of the currently selected vehicle.
Current Car ID display when successfully detected.
Improved compatibility with the FH2 Mod Platform and other mods.

**Information**

All additional stance settings can be found in the original suspension tuning menu under "Springs".

The "Stance (only optical)" section provides additional visual customization options without affecting vehicle handling.

The extended ride height adjustment uses the original front and rear ride height sliders and has impact on the car physic.


**Installation**

This mod requires the **FH2 Mod Platform 2.7.2 or higher**.

https://github.com/Trinculo54/fh2-mod-platform

Azimuth:
Extract the files from this ZIP to Azimuth's main folder where "azimuth.exe" is located.

The "StanceAirride.dll" file must be located inside the "fh2-mods" folder.

If you have an older version of this mod installed, replace the existing "StanceAirride.dll" file.

No additional DLL replacements or modifications to Azimuth are required.
